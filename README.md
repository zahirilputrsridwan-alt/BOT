# Rose-style Telegram Bot

Implementasi open-source bergaya Rose, dibuat sendiri.

Fitur awal:
- Welcome otomatis saat member baru join
- Welcome berupa gambar/card
- Avatar member otomatis dari foto profil Telegram
- Nama member dan nama grup otomatis
- Bahasa Indonesia
- /help /id /adminlist
- /setwelcome /welcome /resetwelcome
- /setrules /rules
- /warn /warns /unwarn
- /mute /unmute
- /ban /unban /kick
- SQLite
- Siap untuk Railway/Docker

Placeholder:
{first} {last} {fullname} {username} {mention} {id} {chatname}
